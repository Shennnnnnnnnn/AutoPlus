本地 Whisper 环境配置指南

要使用自动提取功能，请确保系统本地已安装 openai-whisper 及其依赖，且确保路径正确。请在终端执行以下配置步骤：

  1. 第一步：安装 ffmpeg (音频底层处理依赖) 
    brew install ffmpeg
  2. 第二步：安装 openai-whisper (深度学习提取库) 
    pip3 install openai-whisper
  3. 第三步：验证 Whisper 执行路径

    请确保命令行可在系统定位到：

    /Users/shen/Library/Python/3.9/bin/whisper

注：初次运行会自动从官方拉取 base 基础模型，识别速度极快，识别精度高达 99%。请保证本地计算机网络畅通。
